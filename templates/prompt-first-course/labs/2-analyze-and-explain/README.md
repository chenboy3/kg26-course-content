# Lab 2: analyze and explain

## Learning goal

Build a small evidence set and explain what it supports without overstating the
result.

## Start with this prompt

> Use my question brief to propose a small analysis plan. Ask what I expect to
> find before you calculate anything, and do not show code unless I ask.

## Student work

1. Restate the question and predict the likely pattern.
2. Choose two or three summaries or charts that test the prediction.
3. Check whether missingness, units, outliers, or grouping choices change the
   pattern.
4. Label each finding as observation, interpretation, and decision relevance.
5. Write one alternative explanation and one piece of evidence that would
   change the claim.

## Evidence checkpoint

For each chart or table, answer:

- What do you notice?
- What could produce the same pattern?
- Which business action, if any, does the evidence support?

## Deliverable

Create `analysis.md` and a small `charts/` directory. Keep the report to three
findings, each linked to a table or chart and a limitation.

## Optional deeper coding

Ask OpenCode to show the calculation behind one finding. Modify a filter,
aggregation, or chart and compare the result.
