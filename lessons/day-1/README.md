# Day 1: business dashboard

## Learning goal

Turn an unfamiliar dataset into a defensible business dashboard. Students
should be able to explain what each chart shows, what it does not show, and
which decision it supports.

## Student workflow

1. Fetch Mashina with `/day-1-fetch-data`.
2. Choose a dashboard audience and one business decision.
3. Audit schema, missingness, duplicates, units, and suspicious values.
4. Create a small set of decision-relevant metrics and visualizations.
5. Write three findings with supporting evidence and one limitation each.
6. Save the dashboard and a short analysis note for review.

## Deliverables

- one dashboard view with clearly labeled units and filters;
- one data-quality table;
- three evidence-backed findings;
- one recommendation and its main uncertainty.

## Instructor notes

Ask students to defend chart choice and aggregation level. Do not reward visual
polish that hides missingness, inconsistent units, or selection effects. The
dataset supports course exercises and is not part of the KG26 competition
score.
