# Lab 1: fetch and frame

## Learning goal

Turn an unfamiliar dataset into a business question tied to an audience and a
decision.

## Start with this prompt

> Fetch the Mashina data. I want to understand the used-car market, but first
> help me choose a useful audience, decision, and question.

## Student work

1. Choose an audience, such as a buyer, seller, dealer, lender, or marketplace.
2. Name one decision that audience needs to make.
3. State an initial belief about what the data may show.
4. Review the source manifest, schema, units, missingness, duplicates, and
   suspicious values.
5. Narrow the work to one question that can be supported by this dataset.

## Evidence checkpoint

Before moving on, explain:

- which fields support the question;
- which data-quality issue worries you most;
- what this dataset cannot establish.

## Deliverable

Create `question-brief.md` with the audience, decision, question, initial
hypothesis, useful fields, and main data limitation.

## Optional deeper coding

Ask OpenCode to show the commands or Python used for the schema and quality
checks. Change one check and explain why it matters.
